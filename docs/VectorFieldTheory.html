2.6 Vector Field Theory

2.6.1 Helmholtz Theorem

Electricity and magnetism are generally expressed as electric and magnetic fields, E and B and like many physical laws, these are most compactly expressed as differential equations.

As E and B are vectors, the differential equations naturally involve vector derivatives: divergence and curl. Maxwell reduced the entire theory to four (4) fundamental equations, specifying respectively the divergence and the curl of E and B.

This formulation raises an interesting question:

To what extent is a vector function determined by its divergence and curl?

To study this case lets assume a vector of F. If the divergence of F is a specified scalar function D,

∇ ⁡ · F = D,

and the curl of F is a specified vector function C,

∇ ⁡ × F = C,

and for consistency, we assume C to have NO divergence,

∇ ⁡ · C = 0,
Warning

Remember, the divergence of a curl is ALWAYS zero.

Using this knowledge, is it possible to determine the function F?

Without knowing more information, it is not really possible. There are many functions whose divergence and curl are both zero everywhere.

Some examples are:

F = 0, F = (y)x^ + (zx)ŷ + (xy)ẑ, F = (sin⁡xcosh⁡y)x^ + (− cos⁡xsinh⁡y)ŷ + (.)ẑ

If we recall Higher Mathematics I, to solve a differential equation with a particular solution, we must also be supplied with appropriate boundary conditions.

In electrodynamics we typically require the fields go to zero at infinity. 2.6.2 Potentials

If the curl of a vector field (F) vanishes everywhere, then F can be written as the gradient of a scalar potential (V ):

∇ ⁡ × F = 0⟺F = −∇ ⁡V (2.19)

Knowledge

The minus sign is purely conventional.

That’s the essential idea of the following theorem:

¶ Theory 2.6: Zero Curl Fields

The following conditions are equivalent.

i.
∇ ⁡ × F = 0 everywhere,
ii.
∫ abF · dl is independent of path, for any given end points,
iii.
∮ F · dl = 0 for any closed loop,
iv.
F is the gradient of some scalar function: F = −∇ ⁡V .

The potential is NOT unique as any constant can be added to V , since this will not affect its gradient.

If the divergence of a vector field (F) vanishes everywhere, then F can be expressed as the curl of a vector potential (A):

∇ ⁡ · F = 0⟺F = ∇ ⁡ × A (2.20)

That’s the main conclusion of the following theorem:

¶ Theory 2.7: Zero Divergence Fields

The following conditions are equivalent:

i.
∇ ⁡ · F = 0 everywhere.
ii.
fF · da is independent of surface, for any given boundary line.
iii.
fF · da = 0 for any closed surface.
iv.
F is the curl of some vector function: F = ∇ ⁡ × A.

The vector potential is NOT unique as the gradient of any scalar function can be added to A without affecting the curl, given the curl of a gradient is zero.

Incidentally, in all cases, a vector field F can be written as the gradient of a scalar plus the curl of a vector.

F = −∇ ⁡V + ∇ ⁡ × A
